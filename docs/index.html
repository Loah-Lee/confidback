화면 보면서 말로 피드백하기

글로 정리하실 필요 없습니다. 화면을 보며 말씀만 하시면 개발자가 받아서 정리합니다.

쓰시는 컴퓨터

자동으로 골라 두었습니다. 다르면 눌러서 바꿔 주세요. 아래 안내가 바로 바뀝니다.

1모바일 화면으로 앱 열기

  1. 이 페이지는 그대로 두고, 새 탭에서 개발자가 보내 준 앱 주소를 엽니다. 크롬이 없으면 엣지에서 해도 됩니다. 단축키가 같습니다.
  2. 개발자 도구를 엽니다. ⌘ + ⌥ + I Ctrl + Shift + I (또는 F12)
    화면 빈 곳을 오른쪽 클릭하고 검사를 눌러도 됩니다.
  3. 모바일 화면으로 바꿉니다. 개발자 도구를 한 번 클릭한 뒤 ⌘ + ⇧ + M Ctrl + Shift + M
    개발자 도구 왼쪽 위의 휴대폰·태블릿 모양 아이콘을 눌러도 됩니다.
  4. 화면 맨 위 크기(Dimensions) 목록에서 개발자가 알려 준 기기를 고릅니다. 예: iPhone 14 Pro Max
  5. 새로고침합니다. ⌘ + R F5

개발자 도구가 앱 화면을 가리면 개발자 도구 오른쪽 위 ⋮ → 도킹 위치에서 오른쪽을 고르세요. 마우스가 손가락 역할을 합니다. 클릭은 탭, 끌기는 스와이프입니다.

2녹화하고 말로 피드백하기

  1. 아래 녹화 시작을 누르고 마이크를 허용합니다.
  2. 공유할 화면을 고르는 창이 뜨면 창에서 앱을 띄운 브라우저 창을 고릅니다. 마우스 위치까지 녹화돼야 어디를 가리키셨는지 알 수 있습니다. 시스템의 화면 공유 창이 한 번 더 뜨면 같은 창을 골라 공유를 누릅니다.
  3. 앱 탭으로 가서 화면을 넘기며 편하게 말씀하세요.
  4. 끝나면 화면 위에 떠 있는 작은 창의 녹화 끝을 누릅니다. 이 창은 끌어서 원하는 곳으로 옮길 수 있습니다. 화면 아래 공유 중지를 눌러도 끝납니다.

처음 녹화할 때 화면 기록 권한을 물으면 시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음에서 Google Chrome을 켜고, 크롬을 다시 연 뒤 이 페이지로 돌아오세요.

마이크가 잡히지 않으면 설정 → 개인 정보 및 보안 → 마이크에서 앱의 마이크 사용을 허용해 주세요.

"이 버튼", "여기"라고 말씀하실 때 마우스를 그 위에 올려 두시면 정확하게 전달됩니다. 녹화 파일은 이 컴퓨터에만 저장되고 어디에도 올라가지 않습니다. 녹화가 끝나면 개발자 전용 보관함으로 바로 보내집니다. 개발자만 볼 수 있습니다.

녹화 중 00:00

이제 앱 탭으로 가서 말씀하세요. 녹화 끝 버튼이 있는 작은 창이 화면 위에 떠 있고, 끌어서 옮길 수 있습니다. 말할 때 마이크 막대가 움직이면 제대로 녹음되고 있는 것입니다.

파일 다시 받기파일로도 저장

녹화 버튼이 안 될 때: 컴퓨터 기본 녹화

화면과 목소리가 함께 녹화되면 어떤 방법이든 괜찮습니다. 만든 파일을 개발자에게 보내 주세요. 만든 파일은 이 섹션 맨 아래에서 바로 보낼 수 있습니다.

  1. ⌘ + ⇧ + 5를 누릅니다.
  2. 아래 막대의 옵션에서 마이크를 내장 마이크로 고르고 마우스 클릭 보기를 켭니다.
  3. 전체 화면 기록을 고르고 기록을 누릅니다.
  4. 끝나면 화면 맨 위 메뉴 막대의 ■를 누릅니다. 바탕화면에 동영상 파일이 생깁니다.
  1. Windows 11: Win + Shift + R로 캡처 도구 녹화를 엽니다.
  2. 녹화할 영역을 끌어서 정하고, 위쪽 막대의 마이크 아이콘을 켠 뒤 시작을 누릅니다.
  3. 끝나면 중지를 누르고 저장합니다 (Ctrl + S).
  4. Windows 10: Win + Alt + M으로 마이크를 켜고 Win + Alt + R로 녹화를 시작·종료합니다. 파일은 동영상 → 캡처 폴더에 생깁니다.
  1. Ubuntu 기본 화면 녹화(Ctrl + Shift + Alt + R)는 소리가 녹음되지 않습니다.
  2. 소프트웨어 센터에서 Kooha를 설치하고, 마이크를 켠 뒤 녹화합니다. OBS Studio도 됩니다.
