말로 피드백 녹화

1운영체제 선택

2모바일 화면으로 앱 열기

  1. 크롬 새 탭에서 앱 주소 열기 (엣지도 가능)
  2. 개발자 도구 ⌘ + ⌥ + I Ctrl + Shift + I
  3. 모바일 화면 ⌘ + ⇧ + M Ctrl + Shift + M
  4. 상단 Dimensions에서 기기 선택
  5. 새로고침 ⌘ + R F5

3녹화

  1. 녹화 시작 → 마이크 허용
  2. 창 탭 → 앱 띄운 크롬 창 선택 (시스템 공유 창이 또 뜨면 같은 창)
  3. 앱 화면 넘기며 말하기. 가리킬 땐 마우스 올리기
  4. 떠 있는 창의 녹화 끝 → 자동 전송 → 저장된 파일 개발자에게 전송

권한 요청 시: 시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음 → Chrome 켜고 크롬 재시작

마이크 안 잡힐 때: 설정 → 개인 정보 및 보안 → 마이크 허용

녹화 중 00:00

앱 탭으로 이동. 녹화 창은 끌어서 이동 가능

파일 다시 받기파일로도 저장

녹화 버튼이 안 될 때
  1. ⌘ + ⇧ + 5 → 옵션: 마이크 켜기
  2. 전체 화면 기록 → 끝나면 메뉴 막대 ■
  1. Windows 11: Win + Shift + R → 영역 지정 → 마이크 켜기 → 시작
  2. Windows 10: Win + Alt + M(마이크) → Win + Alt + R(녹화)
  1. Kooha 또는 OBS에서 마이크 켜고 녹화 (기본 녹화는 소리 없음)
